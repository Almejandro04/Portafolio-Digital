Automatización de Bitácoras de Base de Datos

Flujo automatizado para validar, procesar y ejecutar bitácoras SQL sobre bases de datos Oracle desde Azure DevOps Server.

Problema
Un proceso sensible requería ejecución controlada, selección de ambientes y seguimiento claro de errores.
Solución
Pipeline con agente self-hosted, validaciones, manejo de errores, registro de ejecuciones y notificaciones.
Mi participación
Diseño e implementación del flujo, scripts PowerShell y gestión de archivos procesados con Git.
